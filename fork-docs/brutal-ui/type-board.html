Violence: type and colour board

Companion to fork-docs/BRUTAL_UI_SPEC.md (sections 1, 3 and 4). It documents the choices; it is not the app. Sizes use the spec's scale: 1 mockup px = 0.75 dp or sp, then raised to accessibility minimums.

What you are seeing. This page makes no network requests and ships no font files. Each text sample lists the real chosen font first (Archivo Black, Archivo Narrow, Figtree, IBM Plex Mono) and then a common system stand-in. If those four fonts are installed on this computer they show; otherwise you see the stand-ins (wider, rounder or different in weight), so judge the layout, rotation, spacing and colour here, not the exact letter shapes. The real files are about 378 KiB in total (table below).

Custom colour rule: if the chosen colour is under 3:1 on the page, lighten it (5 percent steps toward white) for fills and strokes; if the lightened colour is under 4.5:1 on #2C2C2C, lighten again for text; text on a fill is ink or white, whichever is higher, and if neither reaches 4.5:1 the fill itself is moved. Worked examples are in spec section 3.2.

6. Non-Latin locales: what the heavy display style becomes

None of the chosen fonts covers these scripts, so the system font is used and the display style degrades as follows: no uppercase transform, no letter-spacing (it breaks Devanagari and Thai shaping), no synthetic italic, the same weights (700 or 900) from the system family. The wordmark VIOLENCE stays Latin everywhere. The samples below are drawn with system fonts on purpose.

7. Limits of this board

  • It is static and offline. It does not prove the real fonts look like the mockup; the identification was by eye from enlarged crops and is APPROXIMATE (spec section 4.2).
  • The CSS shapes only illustrate rotation, spacing and colour. The glass itself (refraction, rims, bleed, under-glow) is specified in spec section 2 and cannot be shown in plain CSS.
  • Nothing here was tested on a phone.
